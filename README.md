# DEEP NEST — 보스 러시 (1층: 동굴 여왕 거미)

three.js 3D 보스 러시. 외부 3D 모델/텍스처 없이 **도형 조합 + 절차적 애니메이션**만으로 만든 보스와 아레나(석조 유적 + 화로)입니다.
현재 **1층 보스(동굴 여왕 거미)** 까지 플레이할 수 있습니다. (뱀 → 용은 제작 예정)

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/index.html 하나로 빌드 (파일 더블클릭으로도 실행됨)
npm run typecheck  # 타입 검사만
```

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 (기본 자동 사격) |
| Space | 대시 (0.25초 무적, 쿨 1.2초, 거미줄 감속 해제) |
| Q | 특수기 (게이지 가득 시 등불 투척 폭발, 한 전투에 약 1회) |
| F | 자동 사격 ON/OFF (OFF면 마우스 왼쪽 버튼을 누르는 동안 발사) |
| Esc | 일시정지 |
| M / H | 소리 / 도움말 |
| R | 사망·클리어 후 재도전 |

체력 = 등불 밝기(5칸). 맞을 때마다 등불이 어두워지고, 0이 되면 패배합니다.

### 디버그 키
`1` 무적 · `2` 체력 -1 · `3` 체력 +1 · `4` 특수 게이지 충전 · `5` 보스 공격 ON/OFF · `6` 보스 재시작 · `7` 페이즈 2로 · `8` 보스 체력 5% · `9` 다음 공격 강제 (거미줄→점프→탄막→알→연속점프) · `` ` `` 디버그 표시

## 보스 1 — 동굴 여왕 거미

| 공격 | 예고 | 대응 |
|---|---|---|
| 거미줄 | 직선 마커 | 대시/옆으로 회피. 맞으면 이동 감속 (대시로 해제) |
| 점프 덮치기 | 착지 원 마커 | 원 밖으로. 착지 후 **약점(배) 노출** → 딜 타임 |
| 독침 탄막 | 뒤돌아 배를 치켜듦, 부채꼴 마커 | 틈으로 이동/대시 |
| 알 투척 (P2) | 알이 날아가 착지 | 부화 전(2초)에 알 파괴, 새끼를 모두 처치하면 여왕이 휘청임 |
| 연속 점프 (P2) | 짧은 예비동작 후 3연속 | 한 번씩 원 밖으로 |

- 다리가 화살을 막습니다 — 몸통/배가 보이는 각도에서 쏘세요.
- 배(약점) ×2, 후딜 중 ×3 피해. 체력 50%에서 포효 후 **페이즈 2** (더 빠르고 공격이 늘어남).

## 구조

```
src/
  config.ts          모든 수치 (플레이어, 카메라, 보스 패턴 타이밍/범위/속도 ...)
  palette.ts         색상 팔레트 (금색=플레이어/약점, 붉은색=위험, 상아색=중립). 분위기를 바꿀 땐 여기부터
  types.ts           Target / BossInfo / Host 인터페이스 (보스가 구현/사용하는 계약)
  main.ts            게임 흐름(타이틀·등장·전투·승패), 카메라, 후처리(Bloom), 디버그 키
  player.ts          등불 사냥꾼 (이동/조준/사격/대시/망토/등불/특수기)
  arrows.ts          플레이어 화살 풀
  projectiles.ts     보스 투사체 풀 (독침/거미줄)
  fx.ts              파티클, 공격 예고 마커(원/부채꼴/직선), 충격파 링, 순간 조명
  arena.ts           유적 아레나: 절차 생성 석판 바닥·중앙 문양, 무너진 기둥/외벽, 화로(불꽃·조명), 먼지/불씨
  hud.ts, input.ts   HUD / 입력
  audio.ts           Web Audio 합성 효과음·드론 (외부 음원 없음)
  procedural/
    chain.ts         세그먼트 체인 (망토; 뱀 몸통·용 목/꼬리에 재사용 예정)
    legIK.ts         2본 IK
    gait.ts          보행 (발 고정 + 번갈아 이동하는 다리 그룹)
    pose.ts          이름 붙은 포즈 값을 부드럽게 보간
  bosses/spider/
    rig.ts           거미 모델(도형) + 다리 IK + 포즈 + 피격 점멸 + 파괴 연출
    attacks.ts       공격 스크립트 (예비동작 → 공격 → 후딜 타임라인)
    minions.ts       알 / 새끼 거미
    spider.ts        보스 상태머신, 페이즈, 판정(Target 구현)
```

## 색상 규칙

- **금색·호박색** — 플레이어, 화살, 대시, 특수기, 보스의 약점
- **붉은색** — 위험(예고 마커, 보스 탄, 피격)
- **상아·뼈색** — 거미줄, 알, 송곳니 등 중립 요소
- 배경이 따뜻한 색이라 위험 표시는 밝기 대비(발광 + 밝은 테두리 + 어두운 밑판)로 읽히게 했습니다.

## 다음 단계

새 보스는 `Target`(`types.ts`)을 구현하고 `Host`로 카메라 흔들림/히트스톱/배너를 호출하면 됩니다. 공격은 `bosses/spider/attacks.ts` 의 스크립트 방식을 따라가고, 마커는 `fx.telegraphs.circle / fan / line`, 탄은 `Projectiles` 를 재사용합니다.

권장 순서: 뱀(Chain 재사용) → 용(체인 + 날개 신규) → 보스 전환/업그레이드 선택/엔딩
