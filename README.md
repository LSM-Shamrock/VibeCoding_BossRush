# DEEP NEST — 보스 러시 (1층: 동굴 여왕 거미 · 2층: 심연의 이무기 · 3층: 겁화의 용)

three.js 3D 보스 러시. 외부 3D 모델/텍스처 없이 **도형 조합 + 절차적 애니메이션**만으로 만든 보스와 아레나(석조 유적 + 화로)입니다.
**1층(동굴 여왕 거미) · 2층(심연의 이무기) · 3층(겁화의 용, 마지막 보스)** 을 플레이할 수 있습니다. 한 층을 클리어하면 클릭/R 로 다음 층으로 내려갑니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist/index.html 하나로 빌드 (파일 더블클릭으로도 실행됨)
npm run typecheck  # 타입 검사만
```

## 조작

| 키 | 동작 |
|---|---|
| WASD (또는 방향키) | 이동 (카메라가 보는 방향이 '앞') |
| 마우스 | 시점 회전(위·아래 포함) · 화면 중앙의 조준점으로 조준 — 불꽃은 조준점이 가리키는 곳으로 정확히 날아감 |
| 마우스 왼쪽 버튼 | 누르고 있으면 불꽃이 모이고(약 0.8초, 모이는 소리가 점점 높아짐), 떼면 발사. 모으는 동안 **총구→조준점 점선**이 투사체 경로를 보여 줌. 많이 모을수록 불꽃이 크고 빠르고 훨씬 아프다 (데미지 0.8 → 14, 곡선 ^1.5). 모으는 소리는 불꽃을 빨아들이는 바람 소리(음정 없는 잡음)에 맥동이 겹치며, 맥동 간격이 0.22초 → 0.06초로 점점 빨라지다가 가득 차면 균열음·저음이 터짐 |
| E / 마우스 휠 클릭 | 락온 (보스를 계속 바라봄, 다시 누르면 해제) |
| Space | 대시 (0.25초 무적, 쿨 1.2초, 거미줄 감속 해제). 출발 충격 고리·먼지, 금빛 궤적 띠, 속도 고리, 바람 줄 |
| Shift | 특수기 (게이지 가득 시 등불 투척 폭발, 한 전투에 약 1회) |
| M | 소리 |
| R | 사망·클리어 후 재도전 |
| Esc | 일시정지 (고정) |

체력 = 불꽃 5개. 맞을 때마다 불꽃이 하나씩 꺼지고(꺼진 칸은 점선 윤곽만 남음), 0이 되면 패배합니다. 맞는 순간 화면 가장자리가 붉게 번쩍이고, 체력이 2칸 이하면 가장자리가 계속 붉게 맥동합니다(1칸이면 더 빠르고 진하게).

데미지 숫자는 크기에 따라 색이 변합니다: 1~9 흰색 → 10대 노란색 → 20~30대 주황색 → 40 이상 붉은색.

### 불꽃 차징
- 차징 0~1 에 따라 크기·속도·데미지가 오르고, 데미지는 모을수록 완만하게 가파르게(1.5제곱) 증가합니다. 끝까지 모은 불꽃이 가장 강하지만, 중간까지만 모아도 어느 정도 피해가 나옵니다. (`config.ts` `arrow.damageCurve`)
- **완전 차징(95%↑)**: 맞은 곳에서 **폭발**합니다(반경 3.6). 폭발은 범위 안의 모든 적(보스 몸·다리, 알, 새끼 거미)에게 **직격과 같은 피해**를 줍니다. 직접 맞은 대상은 한 번만 맞습니다. 뭉쳐 있는 새끼 거미를 한 번에 정리할 때 쓰세요. 차징이 덜 되면 폭발 없이 단일 대상만 맞습니다. 모으는 동안 조준점 바닥의 고리가 폭발 범위입니다.
- 거미의 **다리에 맞아도 같은 피해**가 들어갑니다. (포효 중 무적일 때만 막힘)
- 수치는 `src/config.ts` 의 `CFG.arrow` / `CFG.flame` 에서 조정합니다.

### 키 설정
**Esc 로 일시정지**하면 "조작 키" 패널이 열립니다. 칸을 클릭한 뒤 바꿀 키를 누르면 지정됩니다.
- 동작마다 기본/보조 키 2개까지 지정 가능. 설정은 브라우저에 저장됩니다.
- `Esc` 입력 대기 취소 · `Backspace` 칸 비우기 · "기본값으로 되돌리기" 버튼
- 다른 동작이 쓰던 키를 지정하면 그 동작에서 빠지거나(보조 키), 서로 교환됩니다(하나뿐인 키).
- Esc / Enter / 숫자 0~9 / ` / F1~F12 등은 지정할 수 없습니다. (일시정지·확인·디버그·브라우저 용도)

### 디버그 키 (일시정지 화면 하단에도 안내)
`1` 무적 · `2` 체력 -1 · `3` 체력 +1 · `4` 특수 게이지 충전 · `5` 보스 공격 ON/OFF · `6` 보스 재시작 · `7` 다음 페이즈로 · `8` 보스 체력 5% · `9` 다음 공격 강제 (그 보스의 공격을 차례로) · `0` 다음 층 보스로 이동 · `` ` `` 디버그 표시

## 보스 1 — 동굴 여왕 거미

체력바가 3줄이라 한 줄을 다 깎을 때마다 새 체력으로 다시 차오르며 포효(무적 2.3초)와 함께 페이즈가 바뀝니다. 페이즈 1 → 분노(2) → 광란(3). 페이즈가 오를수록 이동·회전이 빨라지고, 예고 시간이 짧아지고, 투사체가 빨라지고, 공격 사이 틈이 줄어듭니다.

| 공격 | 예고 | 대응 |
|---|---|---|
| 거미줄 | 직선 마커 (페이즈 2: 3갈래, 페이즈 3: 같은 줄로 2연발) | 대시/옆으로 회피. 맞으면 이동 감속 (대시로 해제) |
| 거미줄 장판 | 앞다리를 들고 젖힘 → 거미줄 덩어리가 날아가며 착지 고리 표시 | 착지 고리 밖으로. 장판 위에서는 이동속도가 1/3로 느려짐(데미지 없음, 대시로 빠져나옴). 8~10초 뒤 사라짐, 최대 8개. 1번 덩어리는 서 있는 자리, 2번은 가던 방향 앞쪽을 노린다 |
| 점프 덮치기 | 착지 원 마커 | 원 밖으로. 착지 후 **약점(배) 노출** → 딜 타임 |
| 독침 탄막 | 뒤돌아 배를 치켜듦, 부채꼴 마커 (페이즈 2~: 여러 번 엇갈려 발사) | 틈으로 이동/대시 |
| 알 투척 (P2~) | 알이 날아가 착지 | 알에는 체력이 있다 (아래) |
| 연속 점프 (P2~, 페이즈 3은 4연속) | 짧은 예비동작 후 연속 착지 | 한 번씩 원 밖으로 — 쉬지 않고 달려야 한다 |

- **알집**: 체력 13, 위에 체력바가 뜬다. 풀차징(14) 1발이면 깨지지만 부화까지 2초뿐이라 바로 맞혀야 하고, 덜 모은 불꽃이면 2발 이상 필요하다. 부화 전에 부수면 그 알의 새끼는 나오지 않는다. 특수기는 범위 안의 알을 즉시 부순다.
- 다리·몸통 모두 불꽃이 통하지만, 배(약점)를 노리면 훨씬 아픕니다. 배(약점) ×2, 후딜 중 ×3 피해.
- **난이도 조정 (config.ts `spider`)**: 값이 `[페이즈1, 페이즈2, 페이즈3]` 배열인 항목은 페이즈별로 따로 조절할 수 있습니다. 예고 시간은 투사체 공격일수록 더 짧게(거미줄 0.46~0.39초, 탄막 0.62~0.46초), 투사체 속도는 거미줄 21→25~28, 탄막 11.5→14~16.5로 올렸습니다.
- 연속 점프의 반경·예고 시간은 서로 묶여 있습니다 — `(마커 시간 × 7.2) > 반경 + 0.32` 이어야 달리기만으로 피할 수 있습니다 (config.ts 주석 참고).

## 보스 2 — 심연의 이무기 (2층 · 이무기의 못)

몸길이 242의 거대한 구렁이(이무기). 아나콘다처럼 굵고 긴 몸에 고리무늬 비늘, 흰색 바탕 몸에 짙은 얼룩, 목 양옆으로 물갈퀴처럼 펼쳐지는 **목 지느러미(가시 줄기)**, 독니와 갈라진 혀를 가졌습니다(갈라진 혀를 수시로 낼름거리고, 쉬익 소리를 냅니다). 2층은 1층(붉은 유적)보다 **1.5배 넓은 태풍 속 한밤의 연못**(반지름 24)입니다 — 못 한가운데 떠 있는 둥근 석단, 청백색 석등, 부서진 돌다리, 현무암 기둥 군락. 위험 표시(붉은색)와 플레이어(금색)는 푸른 배경 위에서 오히려 또렷하게 읽힙니다. **체력바는 3줄**입니다 — 한 줄을 다 깎으면 포효(무적 2.6초)와 함께 새 체력으로 다시 차오르며 분노 → 광란 페이즈로 바뀌고(보스 이름 옆 ●○○ 로 남은 줄 표시),(몸이 붉게 달아오름), 이동이 빨라지고 예고가 짧아지고 연속 횟수가 늘어납니다.

**몸이 움직이는 방식** — 몸은 머리가 지나간 길을 그대로 따라옵니다(궤적 추종). 그래서 모양을 따로 연출하지 않아도 머리의 움직임이 곧 몸의 모양이 됩니다.
- **S자 사냥**: 평소에는 머리가 좌우로 휘청이며 플레이어 둘레를 휘감듯 돌아 거리를 좁힙니다. 몸 전체가 같은 S자를 그리며 따라옵니다.
- **일직선 돌진**: 돌진하면 몸이 한 줄로 쭉 뻗어 나옵니다.
- **똬리**: 돌진 뒤에는 달려든 방향으로 나선을 그리며 감겨 똬리를 틀고 머리를 높이 쳐듭니다. 한가운데서 다시 튀어 나가면 똬리가 안쪽부터 풀립니다. 잠행에서 솟을 때는 큼직한 나선으로 감긴 채 머리부터 차례로 솟아오릅니다.
- 몸이 자기 몸 위를 지나면 아래 몸 위로 올라타 곡선을 그립니다.

- **약점은 머리** (이마의 마름모 비늘 — 평소엔 청록, 허점을 보이면 호박색으로 타오름). 머리 ×2, 허점(머리를 쳐들고 쉬익거릴 때) ×3, **몸통은 ×0.6** — 몸통은 맞히기 쉽지만 덜 아프고, 몸이 사선을 가리면 불꽃이 몸통에 맞는다. 공격 직후의 틈이 딜 타임이다.
- 몸통은 **멈춰 있을 때만** 플레이어가 통과하지 못한다 (움직이는 동안엔 스쳐 지나감, 데미지 없음). 데미지는 아래 공격(머리 접촉, 독, 충격파, 가시)에서만 들어온다.
- 공격 사이에는 사냥 이동으로 공격에 맞는 거리대(돌진 16~34, 독 뱉기 14~30, 내려찍기 8~15, 독 뿜기 15~25)까지 접근/이탈한 다음 시작한다.

| 공격 | 예고 | 대응 |
|---|---|---|
| 일직선 돌진 | 몸을 쳐들고 목 지느러미를 펴 쉬익 → 조준 고정 후 **붉은 직선**(폭 4.4 = 머리 판정) | 선 밖으로. 페이즈 2: 2연속, 3: 3연속(그때마다 다시 조준, 지그재그). 끝나면 **똬리를 틀고 머리를 높이 쳐들어 허점 노출** |
| 독 뱉기 | 몸을 곧추세우고 내려다봄 → 독액 덩어리가 날아가며 착지 고리 표시 | 고리 밖으로. 착지 자리에 **독 웅덩이**(반경 2.8, 7~9초, 최대 12개): 위에 서 있으면 1초마다 1 피해 (대시로 통과 가능). 1번은 서 있는 자리, 2번은 가던 방향 앞, 나머지는 주변 |
| 내려찍기 | 목 지느러미를 펴고 높이 솟구침 → 바닥에 **원형 예고** → 머리를 내리꽂음 | 원 밖으로. 직후 **충격파 고리**가 바깥으로 퍼진다 (걷는 속도보다 약간 느림: 계속 바깥으로 달리거나, 고리가 닿을 때 안쪽으로 대시 무적). 페이즈 3은 2연속. 후딜에 머리가 바닥에 박혀 허점 노출 |
| 독 뿜기 | **부채꼴 예고** → 머리를 휘저으며 독 방울을 연달아 뿜음 | 부채꼴 밖으로. 조준이 한쪽 끝에서 반대쪽 끝으로 훑는다 |
| 잠행 (P2~) | 머리부터 차례로 땅속으로 가라앉음 (몸 전체 — 이 동안 맞힐 수 없음) → 발밑(과 가던 방향 앞)에 **원 예고**가 연달아 뜨고 뼈 가시가 솟음 | 원마다 벗어난다. **마지막 원에서 머리가 솟구치고** 몸이 새 자리에 큼직하게 감겨 솟는다 — 그 뒤 한동안 머리를 높이 쳐든 채 **허점 노출** |
| 외곽 사격 (P1·P3) | 아레나 **바깥**(석단 둘레의 물 위)으로 나가 몸을 두르고 한 바퀴 넘게 돌며 안쪽 플레이어에게 **보라 독탄**을 쏨 (P3는 3갈래). 끝나면 안쪽으로 들어와 똬리 + 약점 노출 | 탄 밑에 깔리는 **붉은 원**이 실제 피격 범위. 탄 사이로 이동/대시. 바깥에 있는 동안엔 화살이 닿지 않음 |
| 외곽 돌진 (P3) | 바깥을 반 바퀴쯤 돌다가 플레이어를 겨눈 **붉은 직선**이 맵 전체를 가로지름 → 반대편까지 내달림 (3회). 마지막엔 안쪽에서 똬리 + 약점 노출 | 선 밖으로 |

난이도 수치는 `config.ts` 의 `CFG.serpent` 에 모여 있고 `[페이즈1, 페이즈2, 페이즈3]` 배열은 페이즈별로 따로 조절합니다. 돌진/내려찍기의 예고 시간은 `(예고가 보이는 시간 × 7.2) > 반경 + 0.32` 가 되게 잡아 달리기만으로도 피할 수 있지만, 페이즈 3은 대시가 필요합니다. 사냥 속도·휘청임·거리대는 `serpent.hunt` / `serpent.band`, 몸 길이·굵기는 `bodyLen` / `bodyR` 입니다.

## 보스 3 — 겁화의 용 (3층 · 하늘 신전, 마지막 보스)

구름 바다 위 신전 하늘을 날아다니며 싸우는 거대한 용. 머리가 지나간 길(궤적)을 몸통이 그대로 따라가는 **뱀식 절차적 애니메이션**입니다 — 머리 궤적을 호 길이로 샘플링해 마디를 놓고, 진행 방향에 따라 몸이 기울고(뱅킹), 몸을 따라 물결이 전파됩니다. 몸길이는 약 200, 날개 한쪽 길이는 약 90으로 아주 크고(몸이 한 바퀴보다 길어서 선회 고도를 천천히 오르내려 몸끼리 겹치지 않게 합니다), 굵은 뒷다리·앞다리는 날아다니는 자세로 뒤쪽으로 젖혀져 있습니다(`rig.ts` 의 `BODY_LEN` / `WS` / `updateLimbs`). 날개 막·갈기 가시·꼬리 칼날·용암빛 비늘 텍스처 모두 도형과 캔버스 텍스처로 만들었습니다. 체력바는 3줄(페이즈 3개)이며 한 줄을 깎으면 포효(무적 3초)와 함께 다음 페이즈로 넘어갑니다. 3층 아레나는 반지름 24의 대리석 제단입니다(금빛 상감 바닥, 제단을 에워싼 열주와 들보, 발밑은 구름 바다, 멀리 큰 신전, 머리 위는 맑은 낮 하늘).

플레이어 불꽃은 직선으로 날아가므로, 하늘의 용을 맞힐 수 있게 카메라 위쪽 시야 한계를 넓혔습니다(pitchMin -62°). 판정은 3D 구체이며 머리 ×1.5, 몸통 ×0.7, 날개 ×0.5, **추락해 쓰러진 동안 머리 ×3** 입니다.

| 페이즈 | 공격 | 내용 |
|---|---|---|
| 1~ | 화염탄 | 입에 불을 모아 불덩이를 연달아 던진다. 착지 고리가 차오르면 폭발 (P2~ 바닥에 불이 남음) |
| 1~ | 화염 숨결 통과 | 바닥의 긴 예고선을 따라 낮게 날며 불을 뿜는다. 지나간 자리는 한동안 불탄다 |
| 1~ | 저공 돌진 | 굵은 예고선 → 땅을 스치며 머리·몸통으로 쓸어버린다 |
| 2~ | **유성우** (신규) | 용이 하늘 높이 올라 포효 → 불타는 유성이 꼬리를 끌며 쏟아진다 |
| 2~ | **추락 강타** (신규) | 하늘에서 표적 위로 내리꽂아 충격파. 쓰러져 약점(머리)이 드러난다 → 반격 기회 |
| 3 | **태양 광선** (신규) | 입가에 태양을 모아 쏜다. 광선 조준점이 플레이어를 끈질기게 쫓는다 |
| 3 | **날개 충격파** (신규) | 제단 위에서 날개를 내리칠 때마다 땅을 훑는 불꽃 고리가 퍼진다 |

수치는 `config.ts` 의 `CFG.dragon` 에 있고 `[페이즈1, 페이즈2, 페이즈3]` 배열은 페이즈별로 따로 조절합니다. 평소 비행(`cruise`: 선회 반경·고도·속도)과 공격 순서(`sequence`)도 여기서 바꿉니다. 용을 마지막 보스로 두었으므로, 용을 잡고 출구 문으로 들어가면 마지막 클리어 문구가 나옵니다.

## 색상 규칙

- **금색·호박색** — 플레이어, 불꽃, 대시, 특수기, 보스의 약점
- **붉은색** — 위험(예고 마커, 보스 탄, 피격)
- **상아·뼈색** — 거미줄, 알, 송곳니 등 중립 요소
- 배경이 따뜻한 색이라 위험 표시는 밝기 대비(발광 + 밝은 테두리 + 어두운 밑판)로 읽히게 했습니다.

### 이무기 — 구역과 페이즈
- **1페이즈**: 플레이어가 갈 수 있는 맵 **바깥 둘레(외곽)**를 따라 돌며 독 뱉기·독 뿜기·외곽 사격으로 공격하고, 돌진(일직선)할 때만 맵 안으로 들어옵니다. 화살은 바깥까지 닿습니다.
- **2페이즈**: 맵 **안**으로 들어와 안에서만 공격합니다.
- **3페이즈**: 맵 안과 밖을 넘나듭니다 (외곽 사격 · 외곽 돌진 추가).
- **몸 감기**: 맵 안에서 밖으로 나가면(1페이즈 돌진 직후, 외곽 사격·돌진 시작 때) 몸이 전부 맵 밖으로 나올 때까지 외곽을 빠르게 돌며 감고, 그 뒤에야 투사체·다른 공격을 시작합니다 (몸에 가려 투사체가 안 보이는 일 방지). 몸이 지나간 길은 꼬리가 다 지나가야 비므로 돌진 직후엔 몇 초 걸립니다.
- **출구 문**: 보스를 잡으면 맵 반대편에 금빛 문이 솟아오릅니다(`exitdoor.ts`). 문 안으로 들어가야 클리어 화면이 나옵니다.
- **난이도**: 보스 시작 화면에서 고릅니다 — 노멀 체력 5칸 / 하드 3칸 / 크레이지 1칸 (`difficulty.ts`, 선택은 브라우저에 저장). 보스 쪽 수치는 그대로입니다. 화면 흐름: 타이틀(난이도 → 시작) → 전투 → 문 입장 → 클리어 화면(기록, 이동 불가) → [다음] → 다음 보스 소개 화면(보스 이름, 난이도 → 시작). 패배 화면은 재도전 키/클릭으로 바로 다시 시작하고 난이도도 바꿀 수 있습니다.
- **얕은 물과 물결**: 석단 위에도 물이 얕게 고여 돌바닥이 비쳐 보입니다. 플레이어의 발걸음(대시는 더 크게)과 이무기 머리·몸이 지나간 자리마다 물결 고리가 번져 나갑니다(작고 아주 옅고 가늘게). (`Pond.ripple`, 보스는 `wake()` 로 지나간 자리를 알림).
- **몸통 접촉**: 몸통(꼬리 끝 제외)에 닿아 있으면 화면이 보라색으로 (1.5배 빠르게) 물들고, 보랏빛이 0에서 100%까지 짙어지는 1.7초 동안 계속 닿아 있으면 체력 1을 잃습니다.
- **피격음/흔들림**: 피격음은 들어간 데미지에 비례해 가볍게→묵직하게 변합니다. 거미의 내려찍기와 이무기의 돌진(외곽 돌진 포함)은 화면이 크게 흔들립니다 (`host.shake(세기, 유지시간)`).
- **페이즈 효과**: 2페이즈 붉은 불꽃, 3페이즈 검붉은 더 거센 불꽃(두 보스 공통). 페이즈 전환 때 포효(화면 번쩍임·연속 충격파·낮은 울음소리).
